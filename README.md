# 🌾 AI Krishi Advisor

AI-powered agricultural assistant designed to help farmers make better decisions about crops, diseases, fertilizers, irrigation, and weather.

## 🚀 Live Demo

👉 https://nithinsuresh0727.github.io/AI_Krishi_Advisor/

## ✨ Features

- 🌱 Crop recommendation
- 🦠 Plant disease detection
- 🧪 Fertilizer recommendations
- 💧 Irrigation guidance
- 🌦️ Weather information
- 🤖 AI farming assistant
- 💬 Farmer-friendly chat interface
- 🧠 Memory-based assistance

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages
